# 🍔 لوحة تحكم إدارة الطلبات الفورية (Sufriya SaaS - Order Management Dashboard)

نظام ويب متكامل ومخصص لإدارة العمليات التشغيلية للمطعم بلحظيتها (Real-time)، تم تطويره باستخدام إطار العمل **Laravel** مع واجهات تفاعلية حديثة مبنية بـ **Tailwind CSS / AdminLTE** ودعم البث الحي عبر **Pusher**. يهدف النظام إلى أتمتة دورة حياة الطلبات، تفعيل التنبيهات الصوتية والمرئية الفورية، نظام الولاء، وتقديم تحليلات دقيقة لاتخاذ القرار.

---

## 🚀 أبرز الميزات والخصائص المنفذة

### 1. إدارة الطلبات والتنبيهات الفورية (Real-time & Kanban)
- **التنبيهات اللحظية (Pusher & Echo):** استقبال الطلبات الجديدة فوراً دون الحاجة لتحديث الصفحة، مع تحديث عداد الجرس وقائمة الإشعارات المنسدلة تلقائياً.
- **التنبيه الصوتي الذكي (Sound Alerts):** تشغيل مقطع صوتي تنبيهي (رنين جرس) فور دخول أي طلب جديد لتنبيه فريق العمل والمطبخ.
- **تنبيهات الـ Toast العصري:** إظهار إشعارات منبثقة تفاعلية عبر **SweetAlert2** فور وصول طلب جديد مع تفاصيل المبلغ ورقم الطلب.
- **لوحة تفاعلية (Kanban View):** تقسيم الطلبات إلى أعمدة واضحة حسب الحالة التشغيلية للمطعم: *(قيد الانتظار، تم القبول، قيد التجهيز، جاهز للاستلام، مكتمل، وملغي)*.

### 2. نظام إشعارات الواتساب الذكية (FR-11)
- ربط تغيير حالة الطلب في نظام الـ Backend بإرسال وتوثيق إشعارات فورية عبر الواتساب لرقم هاتف العميل.
- تسجيل وتوثيق كافة الإشعارات الصادرة في سجلات النظام (`laravel.log`) لضمان الموثوقية والمتابعة.

### 3. نظام الولاء والترقية التلقائية للـ VIP (FR-14)
- تتبع عدد طلبات العميل وإجمالي المشتريات بشكل آلي مع كل عملية ناجحة.
- ترقية العميل تلقائياً وعرض شارة مميزة (`⭐ VIP`) بجانب اسم العميل في بطاقات الطلبات حصرياً لمن تنطبق عليهم شروط الولاء.

### 4. التحليلات ولوحة الإحصائيات المتقدمة (FR-17)
- عرض مباشر لأهم مؤشرات الأداء (KPIs) في أعلى لوحة التحكم:
  * إجمالي الطلبات المكتملة والإيرادات الكلية.
  * إجمالي العملاء المسجلين في النظام.
  * نسبة العملاء المتكررين (Repeat Customer Percentage) بدقة حسابية عالية.

### 5. تصميم واجهات المستخدم والتجربة (UI/UX)
- تصميم متجاوب (Responsive) بالكامل باستخدام **Tailwind CSS** و **AdminLTE**.
- دعم التبديل السلس وحفظ تفضيلات المستخدم.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)
- **Backend:** PHP / Laravel (MVC Architecture, Eloquent ORM, Events & Broadcasting)
- **Real-time Engine:** Laravel WebSockets / Pusher, Laravel Echo, Pusher JS
- **Frontend:** Blade Templates, Tailwind CSS, AdminLTE, SweetAlert2, Modern JavaScript
- **Database & Tools:** MySQL, Git / GitHub
