🍔 لوحة تحكم مطعم حمزة (Hamza Restaurant Management Dashboard)

نظام ويب متكامل ومخصص لإدارة العمليات التشغيلية لمطعم "حمزة"، تم تطويره باستخدام إطار العمل Laravel مع واجهات تفاعلية حديثة مبنية بـ Tailwind CSS. يهدف النظام إلى أتمتة دورة حياة الطلبات، إدارة علاقات العملاء ونظام الولاء، تفعيل الإشعارات والتنبيهات الفورية، وتقديم تحليلات دقيقة لاتخاذ القرار.
🚀 أبرز الميزات والخصائص المنفذة
1. إدارة الطلبات ودورة الحياة (Kanban Board)

    لوحة تفاعلية (Kanban View): تقسيم الطلبات إلى أعمدة واضحة حسب الحالة التشغيلية للمطعم: (قيد الانتظار، تم القبول، قيد التجهيز، جاهز للاستلام، مكتمل، وملغي).

    التحديث اللحظي: إمكانية تغيير حالة الطلب مباشرة عبر القائمة المنسدلة في البطاقة دون الحاجة لتحديث الصفحة يدوياً.

    إدارة الحذف الآمن: توفير زر حذف الطلب مع نافذة تأكيد منبثقة (Modal) لمنع الحذف الخاطئ وضمان سلامة البيانات.

2. نظام إشعارات الواتساب الذكية (FR-11)

    ربط تغيير حالة الطلب في نظام الـ Backend بإرسال وتوثيق إشعارات فورية عبر الواتساب لرقم هاتف العميل.

    تسجيل وتوثيق كافة الإشعارات الصادرة في سجلات النظام (laravel.log) لضمان الموثوقية والمتابعة.

3. نظام الولاء والترقية التلقائية للـ VIP (FR-14)

    تتبع عدد طلبات العميل وإجمالي المشتريات بشكل آلي مع كل عملية ناجحة.

    ترقية العميل تلقائياً وعرض شارة مميزة (⭐ VIP) بجانب اسم العميل في بطاقات الطلبات حصرياً لمن تنطبق عليهم شروط الولاء.

4. التحليلات ولوحة الإحصائيات المتقدمة (FR-17)

    عرض مباشر ومباشر لأهم مؤشرات الأداء (KPIs) في أعلى لوحة التحكم:

        إجمالي الطلبات المكتملة والإيرادات الكلية (بالشيكل).

        إجمالي العملاء المسجلين في النظام.

        نسبة العملاء المتكررين (Repeat Customer Percentage) بدقة حسابية عالية.

5. تصميم واجهات المستخدم والتجربة (UI/UX)

    تصميم متجاوب (Responsive) بالكامل باستخدام Tailwind CSS.

    دعم الثيمين (Dark/Light Mode) مع زر تبديل سلس وحفظ تفضيلات المستخدم تلقائياً باستخدام localStorage.

🛠️ التقنيات المستخدمة (Tech Stack)

    Backend: PHP / Laravel (MVC Architecture, Eloquent ORM, Routing & Controllers)

    Frontend: Blade Templates, Tailwind CSS, Modern JavaScript

    Database & Tools: MySQL, Git / GitHub
